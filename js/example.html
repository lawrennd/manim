manim-svg demo

Export Manim scenes to per-frame SVG files and play them in RevealJS — no video encoding required. 

class MyScene(Scene):
    def construct(self):
        sq = Square(color=BLUE, fill_opacity=0.5)
        self.play(Create(sq))
        self.wait(1)
manim -r svg my_scene.py MyScene
# → media/svg/MyScene/animation_0/   (frame_0000.svg …)
